# hn-locale

## Когда

Добавление или правка `.ftl` в `Resources/Locale/ru-RU` или `en-US`.

## Запреты

- Не писать русский текст в YAML id/name/description.
- Не менять ключи en-US без нужды (ломает существующие ссылки).
- Не создавать ключи «на глаз» — сверять с прототипом/кодом.
- Не трогать несвязанные `.ftl`.

## Правила

- Entity: `ent-<PrototypeId>` и `ent-<PrototypeId>.desc`.
- Путь locale зеркалит прототип/фичу; автоген часто в `ru-RU/ss14-ru/prototypes/...`.
- Новый HN-контент: `Resources/Locale/ru-RU/_HorizonNova/...` (и en-US при необходимости).
- Чужой файл: комментарий `#HN: ...` **строкой выше** ключа.

## Порядок

1. Взять id прототипа / ключ из кода.
2. Найти соседний `.ftl` того же типа.
3. Добавить только нужные ключи.
4. Проверить отсутствие дубля ключа.

## Чеклист

- [ ] ключ совпадает с id / вызовом в коде
- [ ] ru-RU есть для нового name/desc
- [ ] нет сырого русского в YAML
- [ ] маркер HN на чужих файлах

## Вывод

ПЛАН → фрагмент `.ftl` → ПРОВЕРКА (ключ, в игре name/desc).
