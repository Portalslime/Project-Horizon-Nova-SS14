# hn-port

## Когда

Перенос фичи/прототипов/систем из другой сборки в эту.

## Источники (референс, не править их)

| Имя | Типичная папка |
|-----|----------------|
| Goob | `_Goobstation` |
| Wega | `_Wega` |
| Lust | `_Lust` |
| Fire | `_Fire` |
| Corvax WL | `_Corvax` |

База HN: Lua/Frontier-семейство. Локально у Portal_Slime: `F:\MyGames\...`.

## Запреты

- Не копировать вторую копию, если id/класс уже есть в репо.
- Не тащить RobustToolbox и несвязанные системы.
- Не переименовывать `_*-папки` источников.
- Не «улучшать» порт сверх адаптации под эту базу.
- Не коммитить без указания источника одной строкой.

## Алгоритм

1. Назвать фичу одной строкой + список id/классов.
2. Поиск этих id/классов в HN (`_Lua`, `_NF`, `_Goobstation`, `_Wega`, `_HorizonNova`, корень).
3. Уже есть → не копировать; дописать только недостающее.
4. Нет → минимальный набор файлов:
   - либо в папку источника (`_Goobstation` …),
   - либо в `_HorizonNova`, если сильно переписано.
5. Адаптировать namespace/пути под эту сборку.
6. Locale + спрайты — только нужное.

## Чеклист

- [ ] источник указан
- [ ] поиск на дубли сделан
- [ ] атрибуция папки сохранена
- [ ] namespace/пути под HN
- [ ] маркеры HN при правке чужого
- [ ] ru-RU ключи для новых name/desc

## Вывод

ПЛАН (источник → пути → список файлов) → минимальные правки → ПРОВЕРКА (build, spawn/id).
