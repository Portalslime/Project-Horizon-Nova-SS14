# hn-prototype

## Когда

Новый или правка YAML-прототипа в `Resources/Prototypes/**`.

## Запреты

- Не выдумывать компоненты и поля — только те, что есть в этой сборке.
- Не писать русский в `name`/`description` YAML.
- Не трогать `RobustToolbox`, карты, чужие `_*-папки` без задачи.
- Не создавать дубликат id. Сначала поиск.

## Порядок

1. Определить parent и id (стиль соседей).
2. Поиск id / parent в `_HorizonNova`, `_Lua`, `_NF`, `_Goobstation`, `_Wega`, корень Prototypes.
3. Новый HN → `Resources/Prototypes/_HorizonNova/...`
4. Правка чужого → тот же файл + `#HN`.
5. Locale-ключи: `ent-<Id>` и `ent-<Id>.desc` в ru-RU (и en-US при необходимости).
6. Sprite path = существующее `.rsi` или явно пометить «нужна текстура».

## Чеклист

- [ ] id уникален
- [ ] parent существует
- [ ] компоненты реальны для сборки
- [ ] нет сырого русского в YAML
- [ ] locale-ключи указаны
- [ ] маркеры HN на чужих файлах

## Вывод

ПЛАН → минимальный YAML (полный файл только если новый/короткий) → ПРОВЕРКА (id, spawn, ключ FTL).
